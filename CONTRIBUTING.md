# Contributing

Issues and pull requests are welcome.

1. Create a focused branch from the default branch.
2. Install dependencies with `npm ci --registry=https://registry.npmmirror.com`.
3. Before opening a pull request, run `npm run build`, `npm run typecheck`, `npm run lint`, and `npm test`.
4. Describe the change and the tests you ran.

Please keep changes focused and do not commit secrets or generated files.
